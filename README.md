# Spears Radio (Fabric 1.21.11)
Plays MP3 internet-radio streams, direct MP3 links and .m3u/.pls playlist links. No account needed.
Does NOT play Spotify or YouTube links (they need a login / are DRM-protected).
Keys: I = open screen, \ = play/pause, [ ] = prev/next, - = vol down, = = vol up.
Build: upload to GitHub like Spears (keep .github), run the build action, download the jar.
Repeat: ' (apostrophe) or the Repeat button cycles Off / All / One.
